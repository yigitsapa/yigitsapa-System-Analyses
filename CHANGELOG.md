# Release notes
## v1.0 — Initial Release
First release of **yigitsapa system analyses** package.
### Included
- Consolidated package identity and metadata under `yigitsapa system analyses`, version `v1.0`.
- Added `system_analyses_gui.py`, a Tkinter GUI that launches the main analyzer and streams its standard output and error output into a results area.
- Added `run.bat` for Windows. The GUI opens with the fixed heading **yigitsapa System Analyses Engine**, automatically starts a Quick analysis, and keeps a status bar fixed at the bottom of the window.
- Retained the analyzer's Windows 11 Pro x64 target, optional hardware providers, SMART utility integration, CSV/HTML exports, health history, and benchmark options.
